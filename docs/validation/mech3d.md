## 4. Conduction in a slab

A slab 0 < x < 1.0 m between two plates held at 4.0 K and 30.0 K, adiabatic sides. Constant k = 10.0 W/(m K): T linear (exact for any order). With q = 400.0 W/m^3: T = T1 + (T2 - T1) x/L + q x (L - x)/(2 k), quadratic, so P2 is exact. With the two-point table k(T) = 10.0 (1 + 0.08 (T - 4.0)) the Kirchhoff potential theta = int k dT is linear in x, so T = T1 + (sqrt(1 + 2 c theta/k0) - 1)/c exactly; the solver iterates on k(T_prev) (Picard), so this is a test of the nonlinear path.

The k(T) error is discretization error, not Picard error or a defect of the k(T) evaluation. The Picard iteration stops at a relative change below 1e-10 (column Picard change); it contracts by a factor of about 6 per iteration, so the remaining iteration error is of order 1e-9 K, far below the table. k(T_h) is linear in T_h, so the quadrature (order 2p + 2) integrates the stiffness exactly, and no k(T) table was clamped. The constant-k quadratic case (q) on the same mesh is exact to round-off, which rules out the sinks, the boundary treatment and the assembly. The error is concentrated at the cold end: T(x) = T1 + (sqrt(1 + 2 c theta/k0) - 1)/c has a third derivative proportional to (1 + 8.5 x)^(-5/2), about 40 times larger at x = 0 than at x = 0.4 m, and the line maximum sits at its first point (x = 0.05 m). A pointwise maximum at one point near the steep end of an unstructured mesh only a few elements thick does not have to decrease monotonically (2.2e-3, 2.9e-3, 1.2e-4 K at h = 0.1, 0.05, 0.025 in the first run); the cloud RMS, a mesh-averaged measure, decreases with h, at an average rate of h^2.7 from h = 0.05 m to the finest mesh (P2: 3), once the cold end is resolved (at h >= 0.07 m the slab is two to three elements thick).

## 6. Lorentz loads

**Solenoid hoop stress.** Winding R = 0.5 m, t = 0.05 m, H = 4.0 m, NI = 1e+06 A, E = 1e+11 Pa, unsupported. The magnetic pressure p = (B_in^2 - B_out^2)/(2 mu0) is taken from the solved field just inside and outside the winding at mid-height (probes), so the comparison tests the mechanics. With f_r = J B_z(r) and the linear profile B_z = B0 (b - r)/t, radial equilibrium of an infinitely long solenoid integrates to the thickness-mean hoop stress (1/t) int sigma_tt dr = p (Rm - t/6)/t (the same derivation as the axisymmetric record). The finite length (H/R = 8) is a model error of this reference, beyond what the measured p absorbs (radial B and axial shear near the mid-plane), so the column is FE against an infinite-solenoid model, not a pure discretization error.
