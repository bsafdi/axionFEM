# The quick pre-merge subset: a curated selection of the test suite with a representative of every test file (or a
# stated reason why not), for checking a change before it is merged. It runs in about 30 min on one cluster node
# (16 MPI ranks x 8 threads, ctest included) with AXF_SLOW=1 and AXF_MPI=1: scripts/slurm/tests_premerge.slurm is an
# example job. The full suite (AXF_SLOW=1, 5-7 h on such a node) remains the complete check, for example before a
# release.
#
# One pytest node ID per line (a whole file, a test, or one parametrization); `exclude tests/<file>.py` records a test
# file that is deliberately not represented. Every tests/test_*.py must appear in one of the two forms:
# `python scripts/premerge_tests.py check` fails otherwise, and also when a listed test no longer exists; `run` also
# fails when a test named on its own line, or every test of a listed file, is skipped. Times in the comments are
# full-suite times on that node. Keep the total near 30 min: swap tests rather than grow the list. A new test file
# needs a representative entry here (or an exclude line with the reason).
